# Essays

## What most schools ask for

| Essay | Typical length | Notes |
|-------|----------------|-------|
| **Personal statement** | 2 pages double-spaced (varies) | The core essay; one strong master version, lightly tailored per school's limits |
| **"Why X" / school-specific** | 1 page or a few hundred words | Must contain specifics only true of that school; lives in `school-specific/` |
| **Perspective / diversity statement** | 1 page | Optional at most schools; write it only if you have something real to say |
| **Optional essays** | varies | Prompts change yearly — pull the current prompt into the school's folder first |
| **Addenda** | a few paragraphs, factual | GPA dip, LSAT retakes, character & fitness disclosures. Explain, don't excuse; lives in `addenda/` |

## Workflow

1. Brainstorm in `personal-statement/brainstorming.md` — stories first, themes second
2. Drafts are numbered files in `personal-statement/drafts/` (`v1.md`, `v2.md`, …); never edit an old version, always fork forward
3. Read it aloud before calling any draft done; get at least two outside readers before submitting
4. Tailoring per school (length limits, footer, "Why X" pairing) is noted in that school's folder

## Character & fitness note

Disclose per each school's exact question wording — over-disclosure beats under-disclosure,
because bar admission later will compare answers. Anything disclosed goes in `addenda/`
with a per-school record of what was submitted where.
