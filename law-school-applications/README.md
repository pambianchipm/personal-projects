# Law School Applications — 2026–27 Cycle

Workspace for everything related to applying to law school (targeting Fall 2027 matriculation).

## Structure

```
law-school-applications/
├── README.md                  ← you are here
├── application-tracker.md     ← one-row-per-school status board (deadlines, medians, status)
├── timeline.md                ← the cycle at a glance, working backward from deadlines
├── resources.md               ← LSAC, data tools, and reference links
├── profile/
│   └── profile.md             ← your stats, background, and softs (fill this in first)
├── schools/
│   └── _template/             ← copy this folder per school you're researching
│       └── school-notes.md
├── essays/
│   ├── personal-statement/
│   │   ├── brainstorming.md
│   │   └── drafts/
│   ├── school-specific/       ← "Why X" essays, optionals
│   └── addenda/               ← GPA/LSAT/character & fitness addenda if needed
└── recommendations/
    └── recommenders.md        ← letter-of-recommendation tracker
```

## How to use this

1. **Fill in `profile/profile.md`** — everything else builds on it (school list, essay angles, addenda decisions).
2. **Build the school list** in `application-tracker.md`; copy `schools/_template/` to `schools/<school-name>/` for each school you research seriously.
3. **Draft essays** in `essays/`, one file per draft, numbered (`v1.md`, `v2.md`, …) so history stays readable.
4. **Track letters** in `recommendations/recommenders.md` — ask early; recommenders are the slowest dependency.
5. Keep `application-tracker.md` current; it's the single source of truth for what's due when.

## Ground rules for this folder

- Verify every deadline and median against the school's own site or LSAC before relying on it — numbers in these files are working notes, not authoritative.
- Essays and profile details here are personal; this folder should live in a **private** repo.
