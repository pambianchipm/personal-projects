## Project steps (buyer-visible)

1. **Scope call** — We define exactly what gets automated, what tools it touches, and
   what "done" looks like — in writing, before any build starts.
2. **Access & setup** — You provide access to the tools involved (I'll send a checklist);
   timeline shifts day-for-day if access arrives late.
3. **Build** — I build the automation with a human-approval step anywhere the output
   faces a customer or commits money. You see a working version at the midpoint.
4. **Test & harden** — We run it on real cases together; I handle the edge cases and
   the failure behavior (what happens when the AI is unsure).
5. **Handoff** — Documentation + a walkthrough call. Your team can run, monitor, and
   adjust it without me.

## Requirements from the buyer (asked at order time)

1. Describe the workflow to automate, step by step — who does what today, in what order?
2. What tools/systems does it need to talk to, and do you have admin access to them?
3. How many hours per week does this consume today, and whose hours?
4. Where must a human stay in the loop (approvals, customer-facing sends, payments)?
5. Who maintains this after handoff, and what's their technical comfort level?

## FAQs (answers under 300 chars)

**What counts as "one workflow"?**
One process with a clear start and finish — e.g., "inbound lead email → qualified,
summarized, logged in CRM, draft reply queued." If you're unsure, describe it in a
message and I'll tell you which tier it fits before you order. *(233)*

**What's explicitly out of scope?**
Each order starts with a written scope: deliverables, what's excluded, and milestones.
Changes are welcome — as a scoped add-on, not a silent expansion. This protects your
budget as much as my time. *(199)*

**Will this run without you after handoff?**
Yes — that's the deliverable. Every build ships with documentation, a walkthrough call,
and a design your team can maintain. I offer ongoing support if you want it, but nothing
is built to require me. *(202)*

**What AI tools do you build with?**
Whatever fits: Claude/GPT APIs for language steps, plain scripting where AI isn't
needed, your existing tools wherever possible. You own all accounts and code — no
lock-in to me or any vendor. *(195)*

**What if my workflow turns out to be more complex than the tier I bought?**
I'll flag it at the scope call — before building — and we either trim scope to fit or
upgrade the tier. No mid-build surprises. *(129)*

**Do you offer anything smaller to start with?**
Yes — my AI Workflow Audit project. It identifies and prioritizes what's worth
automating, and the audit fee is credited toward this build within 30 days. *(158)*
