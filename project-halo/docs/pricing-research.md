### 1.4 Price cliffs [S]

- "Magic sizes" are 0.90, 1.00, 1.50, 2.00, 3.00, 4.00, 5.00 ct; a 1.00 ct is worth **10–20 % more** than a 0.99 ct; 0.96 ct is **15–20 % less per carat** than 1.01 ct — https://www.gemsociety.org/article/diamond-carat-weight/ , https://rubyglint.com/diamond-price-per-carat , https://www.rockher.com/blogs/diamond-facts/the-magical-0-95-carat-diamond
- StoneAlgo round data: 0.9→1.0 ct = **+21 % per carat** (+35 % total); 1.0→1.5 ct = +35 %/ct; 1.5→2.0 ct = +62 %/ct; 2.5→3.0 = +4 %/ct; 3→4 = +37 %/ct; 4→5 = +27 %/ct [derived from 1.1].
- Rapaport list uses carat brackets 0.90–0.99, 1.00–1.49, 1.50–1.99, 2.00–2.99, 3.00–3.99, 4.00–4.99, 5.00–5.99; 6–10 ct are priced as % uplifts over 5 ct (e.g., 10 ct D/IF ≈ +30 %) — https://rapaport.com/magazine-article/guide-to-the-rapaport-price-lists/

### 3.3 mm-equivalent sizes
Moissanite is sold by **DEW (diamond-equivalent weight)**; actual weight ≈ DEW × 0.91 (SG 3.21 vs 3.52). Round: 5.0 mm = 0.50, 6.0 = 0.75, 6.5 = 1.00, 7.0 = 1.25, 7.5 = 1.50, 8.0 = 2.00, 8.5 = 2.50, 9.0 = 3.00, 9.5 = 3.50, 10 = 4.00, 11 = 5.00, 12 = 6.00 [S, tables above]. Fancy shapes: use the diamond mm→ct table in §9 (moissanite is cut to diamond proportions).

**Model [E]:** moissanite price ≈ `tier × DEW`, per-DEW-ct: generic-direct $60, mid retail $300, Forever One GHI $400 (drifts to ~$350/ct at 3 ct+), Forever One DEF $620 (flat ~$600–690/ct from 1 to 5 ct). Shape: fancies ≈ round ±10 %.

## 8. Retail economics

- Markups [S]: brick-and-mortar keystone 2× wholesale on jewelry; mall/chain 2–3×+; DTC e-commerce 4–5× COGS on fashion jewelry; **online loose-diamond margins <20 % (often <10 %)**; jewelers make more margin on settings than on diamonds — https://branvas.com/blogs/news/how-to-price-jewelry-for-profit , https://beyond4cs.com/faq/average-markup-on-diamonds/ , https://www.diamonds.pro/guides/diamond-resale-value/ , https://www.jckonline.com/magazine-article/how-much-are-jewelers-marking-up-diamonds/ (JA gross margins: diamond jewelry ~48 %, loose diamonds ~39 %). ### 9.2 Weight-estimation formulas [S]
https://www.omnicalculator.com/other/diamond-weight , https://www.gcalmarketmonitor.com/weight-estimation-formula.html
`ct = L × W × D × SF × GC × WCF` (mm; D = depth)
- Round: d² × D × **0.0061**
- Oval **0.0062**; Cushion **0.00815**; Princess **0.0083** (GCAL 0.0085); Asscher **0.0080**; Heart **0.0059**; Trillion 0.0057
- Emerald by L:W — 1:1 0.0080, 1.5:1 0.0092, 2:1 0.0100, 2.5:1 0.0106
- Radiant — 1:1 0.0081, 1.5:1 0.0084
- Pear — 1.25:1 0.00615, 1.5:1 0.0060, 1.66:1 0.0059, 2:1 0.00575
- Marquise — 1.5:1 0.00565, 2:1 0.0058, 2.5:1 0.00585, 3:1 0.00595
- Girdle correction GC 1.00 (thin–medium) → 1.11 (extremely thick); weight correction WCF 0.97–1.08 (high shoulders, pavilion bulge etc.)

Inverse (carat → dimensions) for the 3D model [E]: with ratio r = L/W and depth fraction p = D/W, `W = cbrt(ct / (SF × r × p))`, `L = r·W`, `D = p·W`. Typical p (depth ÷ width): round 0.615, oval 0.62, cushion 0.66, elongated cushion 0.64, princess 0.72, emerald 0.65, radiant 0.66, pear 0.60, marquise 0.60, asscher 0.66, heart 0.60. export function lerpTable(table, x) {            // table: [[x, y], ...] sorted; duplicate x = cliff
  if (x <= table[0][0]) return table[0][1];
  for (let i = 1; i < table.length; i++) {

}

  benchHourly: 90
};
export const CERT_FEES = { giaNatural: ct => Math.max(90, 110 + 60 * ct), igiLab: ct => 15 + 25 * ct, giaLab: ct => Math.max(15, 15 * ct), none: () => 0 };

// ---------- 8. RETAIL ----------
export const CHANNEL = {   // multipliers on marketplace-level stone price / on (metal+labor) for settings
  marketplace:   { stone: 1.00, setting: 2.8 },
  brandedOnline: { stone: 1.40, setting: 3.3 },
  independent:   { stone: 1.75, setting: 3.5 },
  mallChain:     { stone: 2.50, setting: 4.0 }
};
export const DEFAULT_SALES_TAX = 0.08;
export const KNOT_2026 = { avgSpend: 4600, naturalAvg: 7364, labShare: 0.61, avgCenterCt: 1.7 };

// ---------- 9. DIMENSIONS ----------
export const SHAPE_FACTOR = {  // ct = L*W*D*SF ; ratio-dependent shapes take (r) => SF
  round: 0.0061, oval: 0.0062, cushion: 0.00815, elongatedCushion: 0.00815, princess: 0.0083, asscher: 0.0080, heart: 0.0059,
  emerald: r => lerpTable([[1.0, 0.0080], [1.5, 0.0092], [2.0, 0.0100], [2.5, 0.0106]], r),
  radiant: r => lerpTable([[1.0, 0.0081], [1.5, 0.0084]], r),
  pear:    r => lerpTable([[1.25, 0.00615], [1.5, 0.0060], [1.66, 0.0059], [2.0, 0.00575]], r),
  marquise:r => lerpTable([[1.5, 0.00565], [2.0, 0.0058], [2.5, 0.00585], [3.0, 0.00595]], r)
};
export const TYPICAL_RATIO = { round: 1.0, oval: 1.35, cushion: 1.05, elongatedCushion: 1.25, princess: 1.0, emerald: 1.45, radiant: 1.25, pear: 1.55, marquise: 2.0, asscher: 1.0, heart: 1.0 };
export const TYPICAL_DEPTH_FRAC = { round: 0.615, oval: 0.62, cushion: 0.66, elongatedCushion: 0.64, princess: 0.72, emerald: 0.65, radiant: 0.66, pear: 0.60, marquise: 0.60, asscher: 0.66, heart: 0.60 }; // depth ÷ width
export function dimsFromCarat(shape, ct, ratio = TYPICAL_RATIO[shape], depthFrac = TYPICAL_DEPTH_FRAC[shape]) {
  const sf = typeof SHAPE_FACTOR[shape] === "function" ? SHAPE_FACTOR[shape](ratio) : SHAPE_FACTOR[shape];
  const W = Math.cbrt(ct / (sf * ratio * depthFrac));
  return { lengthMm: ratio * W, widthMm: W, depthMm: depthFrac * W };
}
export function caratFromDims(shape, L, W, D, girdle = 1.0, wcf = 1.0) {
  const r = L / W, sf = typeof SHAPE_FACTOR[shape] === "function" ? SHAPE_FACTOR[shape](r) : SHAPE_FACTOR[shape];
  return L * W * D * sf * girdle * wcf;
}

// ---------- assembly example ----------
export function centerStonePrice({ type, shape, ct, color = "G", clarity = "VS1", cut = "excellent", tier = "fine", channel = "marketplace" }) {
  if (type === "natural") {
    const grid = NATURAL_COLOR_CLARITY[color][CLARITY_INDEX[clarity]];
    return ct * lerpTable(NATURAL_ROUND_USD_PER_CT, ct) * grid * NATURAL_SHAPE[shape] * NATURAL_CUT[cut] * CHANNEL[channel].stone;
  }
  if (type === "lab") {
    return ct * lerpTable(LAB_ROUND_USD_PER_CT, ct) * LAB_COLOR[color] * LAB_CLARITY[clarity] * LAB_SHAPE[shape] * LAB_CUT[cut] * CHANNEL[channel].stone;
  }
  if (type === "moissanite") return ct * MOISSANITE_USD_PER_DEW_CT[tier] * MOISSANITE_SHAPE[shape];
  const bucket = ct < 1 ? "0.5" : ct < 2 ? "1" : ct < 3 ? "2" : "3";
  return ct * GEM_USD_PER_CT[type][bucket][GEM_TIER_INDEX[tier]] * GEM_SHAPE_MULT[shape];
}
export function settingPrice({ alloyKey, widthMm, usSize, head, meleeSpec /* {count, mm, lab} */, labor = [], channel = "marketplace" }) {
  const grams = shankGrams({ widthMm, usSize, alloyKey }) + HEAD_GRAMS_14K[head] * ALLOYS[alloyKey].density / 13.1;
  const metal = grams * alloyUsdPerGram(alloyKey) * (1 + METAL_CASTING_LOSS);
  const meleeCt = meleeSpec ? meleeSpec.count * lerpTable(MELEE_MM_TO_CT, meleeSpec.mm) : 0;
  const meleeWholesale = meleeSpec ? meleeCt * lerpTable(MELEE_WHOLESALE_USD_PER_CT[meleeSpec.lab ? "lab_GH_VS" : "natural_GH_SI"], meleeSpec.mm) : 0;
  const laborTotal = labor.reduce((s, k) => s + LABOR[k], 0) + (meleeSpec ? meleeSpec.count * LABOR.paveStone : 0);
  return (metal + laborTotal) * CHANNEL[channel].setting / 2.8 * ALLOYS[alloyKey].retailMult / ALLOYS["14k"].retailMult
       + meleeWholesale * MELEE_RETAIL_MULT;
}
